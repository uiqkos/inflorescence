    WATCHFIG. 05
    watcher.py · debounced · re-indexes only what changed

    A file changes on disk; the watcher lets the burst settle, re-parses that one file and rewrites its summary and the summaries on its path to the root. Nothing else is touched.

    On the graph: a file flashes changed, then each disc above it flashes summary ↻. The files are picked at random; the path is real.
